# Even or Odd Checker

## Description
This is a simple Python program that asks the user to enter a number and checks whether it is **Even** or **Odd**.  
It demonstrates the use of **Python basics** such as input/output, conditionals, loops, and basic validation.

## Features
- Accepts user input  
- Checks if the input is a number  
- Determines if the number is even or odd  
- Provides option to try again  
- Handles invalid input gracefully  

## Skills Learned
- Python Basics: variables, loops, conditionals  
- Input/Output: using `input()` and `print()`  
- Validation: using `isdigit()` function  
- Program Flow: while loops for repeating actions  

## How to Run
1. Download the `even_odd_checker.py` file  
2. Open terminal or command prompt  
3. Navigate to the folder containing the file
